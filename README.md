# Password_Generator
A Python CLI tool that generates strong, customizable passwords (letters, numbers &amp; symbols) and saves them to a file for safekeeping.

A simple Python command-line tool to generate strong, random passwords.
## Features
- Choose your own password length
- Combines uppercase & lowercase letters, numbers, and symbols
- Guarantees at least one character from each category for stronger passwords
- Displays the generated password instantly
- Option to save generated passwords to a text file (`generated_passwords.txt`)
- Generate multiple passwords in one session

## How to Run
bash
python3 password_generator.py
